## 部署到车上（三步）

车：`192.168.1.3`（LoongOS，root 登录），程序目录 `/home/root`。

```sh
# 1. 把 beaconRace、beacon_race.cfg、hsv_saved.txt 拷到 /home/root/
scp beaconRace beacon_race.cfg hsv_saved.txt root@192.168.1.3:/home/root/

# 2. 板子上赋可执行权限并启动
ssh root@192.168.1.3
cd /home/root
chmod +x beaconRace
./beaconRace --no-drive      # 只看画面，不动电机
./beaconRace                 # 真驱动底盘（比赛模式）
```

常用命令行参数：

| 参数 | 作用 |
|---|---|
| `--no-drive` | 不向底盘发速度，只出画面（调试安全） |
| `--force-card b` / `r` | 强制按蓝卡/红卡路线跑（需 `allow_force_card=true`） |
| `--uart /dev/ttyUSB0` | 指定串口 |
| `--cam 0` | 指定摄像头编号 |

运行后 `ImgStream` 监听 `9999`，PC 端连上即可看实时画面（协议：4 字节大端长度 + JPEG）。

### 终点判定（本版重点）

| 参数 | 值 | 说明 |
|---|---|---|
| `goal_pos_tol` | 0.12 m | 位置进圈才判到点（原 0.25，会停在营地门口） |
| `goal_yaw_tol` | 0.15 rad（8.6°） | 车头必须对准 +x 才算完成 |
| `ENTRY_ALIGN_DIST` | 1.80 m | 距终点多远开始混入航向收敛 |
| `ENTRY_ALIGN_W` | 0.85 | 航向收敛最大权重 |
| `GOAL_ALIGN_MAX_SEC` | 6.0 s | 到点后原地摆正航向的超时兜底 |

逻辑：先按“指向目标点”走，进入最后 1.8 m 逐渐把航向拉向 +x（营地入口方向）；
位置进 0.12 m 圈后若航向仍超差，则以 0 线速度原地转正，最多 6 秒。

## 已知问题（不影响比赛判定）

1. **DONE 之后 yaw 读数发散**：停车后日志里 yaw 会在十几秒内乱跳（如 84°→162°→−124°），
   但位姿不变、指令为 0，且上位机画面变化率仅 1%（证实车并未转动），属于航向估计失效。
   只影响停车后的日志读数，不影响位置判定与比赛成绩。
2. **丢线率约 45%**：全程约一半帧没识别到黑点，走 `LOST_VX` 兜底速度 + 里程计。
   若想提速，优先改善黑点识别（`min_black_area`、`roi_y_top`、光照），而不是继续加 `vel_x_vision`。
3. `red_avoid_wz` / `blue_avoid_wz` / `*_avoid_vx` 这四个 cfg 参数**已失效**（对应函数未被调用），
   真正生效的避让强度是源码常量 `AVOID_YAW_MAX/RATE/RECOVER` 与 `CONE_PATH_HALF_W`。
