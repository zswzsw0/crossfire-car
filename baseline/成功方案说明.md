## 相对原始代码的四处关键改动

### 1. 新增「避让限时」机制

原代码只要画面里有锥桶就无限转向，4 秒能转 103°，必然跑出场地。

```cpp
static constexpr int AVOID_MAX_FRAMES = 45;   // 约 1.5s
int avoid_frames_ = 0;
```

### 2. 锥桶「是否挡路」判定统一（红蓝共用）

原代码红锥完全不过滤（画面里任何红块都触发避让），蓝锥要求距黑点连线 ≤40px（赛道边缘的蓝锥永远不触发）。

```cpp
bool pickConeInPath(const std::vector<Blob>& cones, double min_area,
                    const Track* track, Blob& out) const
{
    double ref = track ? track->mid_x : CENTER_X;
    std::vector<Blob> on;
    for (const auto& b : cones) {
        if (b.area < min_area) continue;
        // 阈值随距离自适应：越近允许的横向偏差越大
        double thr = CONE_PATH_HALF_W + 90.0 * (b.cy / static_cast<double>(IMG_H));
        if (std::abs(b.cx - ref) <= thr) on.push_back(b);
    }
    return pickNearest(on, min_area, out);
}
```

### 3. 走廊回归约束（最关键）

给车一条 `base→goal` 的回归线，横向偏差超过 0.55 m 就强制拉回。这是"不跑出场地"的根本保证。

```cpp
double ux = goal_x_ - base_x_, uy = goal_y_ - base_y_;   // 归一化
double cross = -(x_ - base_x_) * uy + (y_ - base_y_) * ux;
double over  = std::abs(cross) - CORRIDOR_HALF_W;        // 0.55 m
if (over > 0) corridor_wz = -std::copysign(CORRIDOR_GAIN * over, cross);
```

### 4. 避让改用「有界航向偏置」

底盘实测**不执行 y 分量**（麦轮横移不可用），所以用有界转向代替：

```cpp
const double off_dir = (card_color_ == "blue") ? -1.0 : 1.0;  // 红卡→左，蓝卡→右
avoid_yaw_ += off_dir * AVOID_YAW_RATE;                        // 0.03/帧
avoid_yaw_ = clampd(avoid_yaw_, -0.65, 0.65);                  // 上限 37°
wz += avoid_yaw_ * 2.0;
```

锥桶过后按 0.015/帧 自动回正。因为偏置角封顶，所以**不会像原版那样绕圈**。

## 已知限制 / 排错

1. **关于「板子频繁重启」** ⭐：曾观察到板子多次重启（uptime 归零），一度怀疑电机电流/供电掉压。
   **后确认是人为手动重启** —— 原因是当时连错了车（现场不止一块板/一台车，IP 都可能被 DHCP 分到 192.168.1.3）。
   结论：**重启不是故障**，与电机电流、WiFi 发射都无关，也**不需要**用 `--no-stream` 去规避。
   排查方法：连上后先看 `cat /sys/class/net/wlan0/address`，用 WiFi MAC 确认是不是目标那块板（本项目那块是 `1c:79:2d:96:84:15`）。
2. **头文件与库版本不一致**：板子的 `opencv/include` 是旧版（`cvtColor` 4 参数），库是 4.11（5 参数含 `AlgorithmHint`）。
   已在 `~/loongarch-opencv/opencv/include/opencv4/opencv2/imgproc.hpp` 里打补丁（补 `enum AlgorithmHint` + 尾参数），原文件备份为 `.orig`。
3. **底盘不执行 vy**：实测避让期间速度仅 ~0.09 m/s（等于 vx），`sendVelocity` 的 y 分量无效，所以不能用横移避障。
4. **WiFi 会掉**：板子 WiFi 不稳定，掉线后 `192.168.1.3` 不可达，需等板子重新上线。
5. **部署前务必确认文件大小**：曾有 `/opt/beaconRace` 被写成 0 字节（写入中断）导致启动无任何输出。
6. **`--drive` 不是合法参数**：程序只有 `--no-drive`，不带参数即为实跑。
